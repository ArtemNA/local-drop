Release notes for Local File Transfer

v2.2.0 October 20, 2026 Latest

New

  • LAN only switch for Shared text (off by default). When it is on, text goes directly from device to device over the encrypted peer-to-peer connection, the same way files do, and never passes through the server. Only devices confirmed to be on your local network receive it.
  • When a device shares text in LAN-only mode, devices that receive it switch to LAN only too, so the text stays inside the local network.
  • This page. Click the version number at the bottom of the app to open it.

Improved

  • More reliable connection when two devices connect to each other at the same moment.
  • Shared text and file transfers can use the same connection at the same time without stalling each other.
v2.1.0 update July 9, 2026

New

  • Shared text: a live shared clipboard for everyone in the room (or on the local network in local mode). Open it with the round button in the corner.
  • Syntax highlighting for common languages, plus Copy and Clear-for-everyone buttons.
  • Formatting is preserved exactly, so pasted code copies back byte-for-byte on another device.
  • Large texts are supported, and devices that join later receive the current text.
v2.1.0 April 2, 2026

New

  • The app version and deploy time are shown at the bottom of the page.
  • Connection check before sending files: transfers over a verified local route start right away, and you are asked to confirm when the route cannot be verified.

Improved

  • Faster transfers of large files and archives.
  • Very large files can be saved straight to disk in supported browsers.
  • Received files are checked for completeness.
  • Fixes for interrupted and stalled file transfers.
Earlier releases August 2025
  • First release: peer-to-peer file transfer between devices in the browser.
  • Rooms with 6-character codes and shareable room links for use over the internet.
  • Automatic rooms for devices on the same network.
  • Send files by drag & drop or by tapping a connected device (mobile-friendly).
  • Editable device names, synced to other devices.
  • Dark theme by default, with a light/dark switch.
  • Better reliability for large files.
