Release notes for Local File Transfer

v2.5.1 October 21, 2026 Latest

Improved

  • A file shows as sent only after the receiving device confirms it saved it. If the receiver refuses it (LAN only) or it arrives incomplete, the sender sees that instead.
  • If a device only accepts files over its local network, you see this on its card before sending.
  • Better layout on phones: the header fits the screen, devices are shown as compact rows, and notifications no longer cover the shared-text button.
v2.5.0 October 21, 2026

New

  • LAN only now covers files as well as shared text, with one switch at the top of the page (on by default). Files are sent to and accepted from devices on your local network only. Turn it off to send over the internet — still encrypted and directly between the devices.
  • Devices that are not on your local network are marked on their card.
  • Shared text shows whether an update arrived through the server or over the local network.

Improved

  • More accurate detection of whether two devices are really on the same network. Some connections between different networks were treated as local before.
  • Receiving local-only text no longer switches your own LAN only setting; that text simply isn't sent through the server.
v2.4.0 October 21, 2026

New

  • Verify a connected device: both devices show the same 6-digit code. If the codes match, nobody is intercepting the connection between them. Press "Codes match" on each device.
  • Verified devices are remembered and marked as verified the next time they connect.
  • If the codes differ, the connection is closed and is not re-established automatically.
v2.3.0 October 21, 2026

New

  • LAN only is now on by default for Shared text, so text stays inside your local network unless you turn it off. If you turned it off before, your choice is kept.
  • Pause and Resume now work from either device and continue exactly where the transfer stopped. After a brief connection drop, transfers continue automatically.
  • Save to disk button for very large incoming files, so they are written straight to a file instead of being kept in memory (in supported browsers).
  • Newest transfers appear at the top of the queue.

Improved

  • Received files are checked before they are saved; an incomplete file is no longer saved.
  • Sending several batches of files to the same device at once is now reliable.
  • The app reconnects to the server more persistently after a network hiccup.
  • The app starts faster.
  • Automatic rooms now group devices that share the same internet connection.
  • Room codes must be 6 letters or digits.
  • Very large shared texts (over about 10 MB compressed) sync only in LAN-only mode.
  • Stability and security improvements.
v2.2.0 October 20, 2026

New

  • LAN only switch for Shared text (off by default). When it is on, text goes directly from device to device over the encrypted peer-to-peer connection, the same way files do, and never passes through the server. Only devices confirmed to be on your local network receive it.
  • When a device shares text in LAN-only mode, devices that receive it switch to LAN only too, so the text stays inside the local network.
  • This page. Click the version number at the bottom of the app to open it.

Improved

  • More reliable connection when two devices connect to each other at the same moment.
  • Shared text and file transfers can use the same connection at the same time without stalling each other.
v2.1.0 update July 9, 2026

New

  • Shared text: a live shared clipboard for everyone in the room (or on the local network in local mode). Open it with the round button in the corner.
  • Syntax highlighting for common languages, plus Copy and Clear-for-everyone buttons.
  • Formatting is preserved exactly, so pasted code copies back byte-for-byte on another device.
  • Large texts are supported, and devices that join later receive the current text.
v2.1.0 April 2, 2026

New

  • The app version and deploy time are shown at the bottom of the page.
  • Connection check before sending files: transfers over a verified local route start right away, and you are asked to confirm when the route cannot be verified.

Improved

  • Faster transfers of large files and archives.
  • Very large files can be saved straight to disk in supported browsers.
  • Received files are checked for completeness.
  • Fixes for interrupted and stalled file transfers.
Earlier releases August 2025
  • First release: peer-to-peer file transfer between devices in the browser.
  • Rooms with 6-character codes and shareable room links for use over the internet.
  • Automatic rooms for devices on the same network.
  • Send files by drag & drop or by tapping a connected device (mobile-friendly).
  • Editable device names, synced to other devices.
  • Dark theme by default, with a light/dark switch.
  • Better reliability for large files.
